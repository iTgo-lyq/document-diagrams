# Bybit 视觉与 diagram-design 语义的映射

配色和字体的原始定义以 [Bybit SKILL](../upstream/svg-diagram/SKILL.md) 的 Style rules、Arrowhead definitions 为准，图形外观可参考 [house-style.svg](../upstream/svg-diagram/assets/house-style.svg)。本文件只维护组合差异。

## 视觉角色

| diagram-design 中的角色或用途 | 本组合映射 |
|---|---|
| `paper` | 白色；独立 SVG 也绘制白色底，保证嵌入深色阅读器时清晰 |
| `paper-2` | Bybit 容器浅灰底，或不额外填充 |
| `ink` / 主正文 | Bybit 主文本色 |
| `muted` / `soft` / 默认连接线 | Bybit 次级文本色、浅灰线色，按用途选择 |
| 节点填充、边框、节点标题 | 使用 Bybit 蓝、橙、绿、紫、粉的成套组合；按内容分组保持一致 |
| `accent` / `accent-tint` / `link` | 从对应节点或路径的 Bybit 成套颜色中选择；不沿用珊瑚色 |
| 节点、标题、辅助文字 | Bybit 的中文无衬线字体栈；长技术标识按需单独处理 |

不叠加 diagram-design 的奶油纸色、衬线标题、等宽副标题、点阵背景或默认卡片海报布局。通过分组、层级、线型和少量强调建立重点，不要求每个节点使用不同颜色，也不只靠颜色表达含义。

## 中文阅读与空间

保留 Bybit 的 CJK 字体栈，允许当前平台的中文字体回退。默认不联网下载字体。

800px 文档宽度下，主要图内标签以实际显示 14–16 CSS px 为目标；用 `viewBox` 缩放后的最终大小判断。必要辅助文字也应清晰，不照搬上游模板的 10/12px 默认值。使用真实渲染检查字宽和换行，不只估算字符数。

使用 Bybit 的细线和克制圆角：普通节点约 6px，分组容器约 8–12px。节点尺寸由字号、内容和内边距决定。25–30px 紧凑间距是参考，遇到中文长标签、条件片段或多条消息时增加空间；增加空间仍难以阅读时拆图。

## 连线与语义

类型专属规则决定如何表达连接，Bybit 决定线条和箭头的视觉处理：

- 共轴关系可直接连线；一般绕行可使用清晰的平滑曲线。
- 所选类型依赖正交布线时，保留 diagram-design 的圆角正交表达，不为了 Bybit 的通用曲线建议扭曲结构。
- 时序图保留生命线、消息先后、条件片段及调用/返回的区别；状态图保留转换条件。箭头不能为了美观暗示不存在的依赖或数据流。
- 箭头与目标边界保持可辨认的端点；标签与线错开或使用白底遮罩。不能让连接线穿过无关节点或文字。

正文使用简单的标题、段落和必要表格。SVG 是文档中的插图，图内不重复正文段落。
